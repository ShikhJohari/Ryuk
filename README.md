# Ryuk

Watchlist face recognition, built as a machine learning project. A Python service detects faces, turns them into embeddings with open-source pretrained models, matches them against an enrolled watchlist, and reports how well each model does on public benchmarks. A React client shows the watchlist, the live monitor, and the evaluation results.

This is the successor to [crimdet](https://github.com/ShikhJohari/crimdet), a Java desktop app that wrapped the same pipeline without measuring it. Ryuk keeps the pipeline design and adds the parts a machine learning project needs: datasets, exploratory analysis, an evaluation harness, model comparison, and a bias breakdown.

## Status

Building. The spec is [#22](https://github.com/ShikhJohari/Ryuk/issues/22); its sub-issues are the build tickets. `docs/handoff/` holds the session records, `docs/research/` the research write-ups, `docs/agents/` the tracker and glossary conventions the engineering skills read.

## Layout

```
src/ryuk/        Python package: the FastAPI service (api/), the YuNet detector, the
                 recognition models (recognition/), the evaluation harness (evaluation/),
                 data and weights fetch (fetch/, weights.py), settings, CLI
tests/           pytest, in-process against the service's HTTP surface; fixtures/ holds the
                 YuNet weights and a public-domain face for the detector tests; smoke/ runs
                 the real models and needs the fetched weights and LFW
evaluation/      results.json, every measured number, and its generated JSON Schema
notebooks/       one notebook per measured phase, reading committed JSON only
openapi.json     the API contract, generated by the service and committed
web/             React client (TanStack Router, Effect, shadcn, Tailwind)
docs/adr/        architecture decision records
CONTEXT.md       glossary
```

## Running it

Needs [uv](https://docs.astral.sh/uv/) and pnpm (the version pinned in `web/package.json`).

```sh
uv sync
uv run ryuk serve                 # service on http://127.0.0.1:8000, localhost only

cd web
pnpm install
pnpm dev                          # client on http://localhost:5173, proxies /api to the service
```

## Data and weights

Both are fetched from pinned sources and checked against pinned checksums; a file is renamed into place only after its checksum passes, and a rerun skips anything already verified. Neither is ever committed.

```sh
uv run ryuk weights fetch         # YuNet, SFace (fp32 and int8), ArcFace w600k_r50, FaceNet VGGFace2 into models/weights (~335 MB)
uv run ryuk data fetch            # LFW and CelebA (valid and test images, all labels) into data/raw (~2.6 GB)
uv run ryuk data fetch --dataset lfw   # LFW alone
```

`RYUK_WEIGHTS_DIR` and `RYUK_DATA_DIR` move them. LFW is research-only by convention and CelebA is under the CUHK non-commercial agreement, which forbids redistribution; the weights carry their own licences (InsightFace's are non-commercial research only).

## Evaluation

The evaluation commands write `evaluation/results.json`, which is committed; the notebooks, the report and the service read it and nothing else. Benchmark embeddings are cached under `data/cache` (`RYUK_CACHE_DIR`), never in the app database.

```sh
uv run ryuk evaluate lfw          # every recognition model on LFW View 2 (a few minutes on Apple Silicon)
uv run ryuk evaluate schema       # regenerate evaluation/results.schema.json after changing the results model
```

Run the evaluation from a clean, committed tree: the results record the commit and whether the tree was dirty.

## Checks

CI runs all of these on every pull request.

```sh
uv run ruff check . && uv run ruff format --check . && uv run mypy && uv run pytest
uv run pytest --nbmake notebooks --no-cov
uv run pytest -m smoke --no-cov   # the real models; needs `ryuk weights fetch` and `ryuk data fetch --dataset lfw`

cd web
pnpm typecheck && pnpm lint && pnpm test && pnpm build
```

After changing any API model, regenerate the contract and the client's types, and commit both:

```sh
uv run ryuk openapi && pnpm --dir web gen:api
```

The browser smoke test (`pnpm e2e`) runs headless in CI.
